# NovaFlow Labs

Landing page for **NovaFlow Labs**, a web automation brand: *"Automating connections, driving growth."* The site content is in Spanish.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## What it covers

The page presents the brand and its services:

- API integrations
- Process automation
- AI-based solutions
- Custom software development

It also includes a contact section and a privacy policy page.

## Structure

```
index.html     # Landing page
privacy.html   # Privacy policy
```

It is a static site with no build step: open `index.html` in a browser, or serve the folder with any static host such as GitHub Pages.
